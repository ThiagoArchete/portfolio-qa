> **Qualidade não é uma fase do projeto. É um critério de aceite em cada entrega.**

Este repositório funciona como um índice dos meus projetos de Quality Assurance.

Cada projeto está organizado em um repositório próprio, contendo documentação, planejamento, execução dos testes, evidências e resultados obtidos durante a validação de aplicações Web e APIs.

---

# 📌 Sobre este Portfólio

Acredito que a melhor forma de demonstrar conhecimento em QA é por meio de projetos práticos.

Por isso, cada repositório reúne um ciclo completo de testes realizado sobre um sistema real ou uma aplicação pública, incluindo desde o planejamento até o registro das evidências encontradas.

Os projetos têm como objetivo:

- aplicar técnicas de testes em cenários reais;
- praticar documentação e organização dos artefatos de QA;
- desenvolver raciocínio analítico durante a execução dos testes;
- construir um histórico de evolução contínua.

# 📋 O que cada projeto contém

Embora cada sistema possua características próprias, todos os repositórios seguem uma estrutura semelhante e podem incluir:

- Plano de Teste
- Casos de Teste
- Testes Exploratórios
- Relatórios de Bugs
- Evidências (prints, vídeos ou logs)
- Coleções do Postman (quando aplicável)
- Cenários BDD/Gherkin (quando aplicável)
- Automações (quando aplicável)
- Considerações finais sobre os resultados
